# ADR 0036: Repository enterprise-ai-control-plane with the eacp attribute prefix

- Status: accepted
- Date: 2026-11-06
- Decided in: design round 3, question Q36

## Context

The name goes on the repository, the charts, the realm and every custom span and audit
attribute.

## Decision

Repository enterprise-ai-control-plane; prefix eacp. for attributes, labels, headers and
environment variables.
