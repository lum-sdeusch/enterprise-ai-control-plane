# ADR 0049: Publish under the organisation's GitHub, cross-post the article, generate ADRs, record a short video

- Status: accepted
- Date: 2026-11-06
- Decided in: design round 3, question Q49

## Context

A company-backed repository gets more trust; the decisions made in the rounds are the most
reusable part of the publication.

## Decision

The repository lives under Lumenalta's GitHub organisation if they host it. The article is
cross-posted. One ADR per decision, generated from a structured log. A demo video under ten
minutes shows the six scenarios.
